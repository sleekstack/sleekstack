# @sleekstack/model

Models, Drafts and records for apps on the `@sleekstack/ui` host (ADR 0038, ADR 0041, ADR 0057). Install it to opt in: `@sleekstack/core` and `@sleekstack/ui` do not depend on this package, and it pulls neither `react` nor the router into a bundle.

| Export                                                                                                                                        | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ModelSpec<Dto, M, Ctx>`, `DraftSpec<D, Dto, Src, P, E, R>`                                                                                   | Types only: the read direction of a Model (a pure `fromDto(dto, ctx)`) and its write direction (`schema` with Type = Encoded, `create`, `toDto` as an Effect with typed `E` and `R`, optional `toModel` and `diff`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `useDraft(spec, src)`, `Draft`                                                                                                                | An editable copy of a Model from a `DraftSpec`: atoms `value`, `field(name)` (a plain record's keys or an array's indexes; a primitive or class-instance Draft writes `value`, and `field` throws a `TypeError` on an instance), `errors` by field path, `valid`, `dirty` (the schema's equivalence against the seed), `preview` (with `toModel`) and `changes` (with `diff`), each computed only when read; `reset()`; `toDto()`, an Effect that validates with the schema and runs `spec.toDto` (yield it in a form action; failures stay in the `Result`). `src` is a value or an atom: a pristine Draft re-seeds when it changes, an edited one keeps its edits. No source: `useDraft(Spec, undefined)`. Same slot rule as `useLocal`; outside a component it returns a Draft without a slot. |
| `defineRecord(type, { fields, adapter? })`, `RecordDefinition`, `AdaptedRecord`, `RecordFields`, `RelationKey`                                | A Record Type: one record per type and id in each Store's Identity Map. `atom(id)` reads it (`None` until pushed), `push(wire)` hydrates and replaces it (a `ParseError` writes nothing), `evict(id)` empties it, `related(id, field)` reads a relationship, `useDraft(id)` derives its Draft. With an adapter (`AdaptedRecord`) it also has `find(id)` (adapter `find`, hydrate, write; in-flight calls for one id shared; a response older than the last acknowledged save dropped) and `commit(id, draft)` (validate, serialize, adapter `save`, write the acknowledged record; pessimistic). A record stays until the Store is disposed or evicted. Client-only.                                                                                                                              |
| `defineTransformation(name, options => parts)`, `field(transformation, options)`, `Transformation`, `TransformationParts`, `TransformedField` | A per-field wire format: `from`, `to`, `hydrate` (wire to input, on ingest), `serialize` (input to wire, on commit), `defaultValue` (an `undefined` wire value, a new record's Draft). Both directions fail with a typed `ParseError`. Passed as a value; one field only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `ref(() => Target)`, `refs(() => Target)`, `RecordRef`, `Related`, `RefField`, `RefsField`, `RelationTarget`                                  | To-one (wire `string \| null`) and to-many (wire `string[]`) relationship fields. `related(id, field)` holds `RecordRef { id, value: Option }` entries, follows the owner and every target in the map and never fetches; a missing target keeps its id and position. One direction only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `RecordAdapter<W, C, E>`, `AdapterTag`, `FindError`, `SaveError`                                                                              | The shape of a record type's adapter Service: `find(id)` and `save(id, change)`, Effects returning the wire form with the envelope removed and failing in `E`. The app declares the `Effect.Tag` and supplies the Layer, so a missing adapter shows in `R`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `useRecord(record, id, options?)`, `FetchStrategy`                                                                                            | A slot hook: the record from the map as a `Result` (waiting on first load, success with the map's value and kept during a refetch, typed failure), fetching once while the map has none, with the record's `find` or `options.via`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `SaveInFlight`, `SaveResponseError`, `RecordDraft`, `RecordInput`, `RecordChange`                                                             | `commit`'s failures (a second commit of a record while one saves; a save whose response does not hydrate or is another record), the derived Draft's type, what it holds (every field but `id` and the `readOnly` ones, in input form) and what `commit` sends to `save`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `readOnly(schema)`, `record.change`                                                                                                           | A field the client reads and never writes (`createdAt`; `id` always is): kept in the record and the wire form, left out of the Draft, `RecordChange` and `record.change`. `record.change` is the Schema of a PATCH body: every editable field, required, in wire form; decoding drops read-only and unknown keys.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `RecordNotFound`, `RecordRejected`                                                                                                            | Tagged errors `{ type, id }` and `{ type, id, message }`: the failures of a served record's adapter. `records(Record)` of `@sleekstack/start` answers them 404 and 422, and the generated browser adapter fails with them on 404 and on 400 or 422 (ADR 0057).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `queryOf(record)`, `RecordQuery` (entry `@sleekstack/model/query`)                                                                            | The record's query binding over the Query Client (`QueryClientTag`, key `[type, id]`): `query(id)` caches, de-dupes and writes every read (cache hits and hydrated entries included) into the map unless older than the last acknowledged save; also a `FetchStrategy` for `useRecord(record, id, { via: queryOf(record) })`. Its Query Client Layer needs the Store and the adapter Layer.                                                                                                                                                                                                                                                                                                                                                                                                       |

`useDraft`, `useRecord` and `record.useDraft` are slot hooks built on the `@sleekstack/ui/internal` extension point. `effect`, `@sleekstack/core` and `@sleekstack/ui` are peer dependencies; `@sleekstack/query` and `@tanstack/query-core` are optional peers, needed only by the `@sleekstack/model/query` entry. A bundle that imports only `useDraft` holds no records code.
