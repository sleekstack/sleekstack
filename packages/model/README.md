# @sleekstack/model

Models and Drafts for apps on the `@sleekstack/ui` host (ADR 0038). Install it to opt in: `@sleekstack/core` and `@sleekstack/ui` do not depend on this package, and it pulls neither `react` nor the router into a bundle.

| Export                                                      | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ModelSpec<Dto, M, Ctx>`, `DraftSpec<D, Dto, Src, P, E, R>` | Types only: the read direction of a Model (a pure `fromDto(dto, ctx)`) and its write direction (`schema` with Type = Encoded, `create`, `toDto` as an Effect with typed `E` and `R`, optional `toModel` and `diff`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `useDraft(spec, src)`, `Draft`                              | An editable copy of a Model from a `DraftSpec`: atoms `value`, `field(name)` (a plain record's keys or an array's indexes; a primitive or class-instance Draft writes `value`, and `field` throws a `TypeError` on an instance), `errors` by field path, `valid`, `dirty` (the schema's equivalence against the seed), `preview` (with `toModel`) and `changes` (with `diff`), each computed only when read; `reset()`; `toDto()`, an Effect that validates with the schema and runs `spec.toDto` (yield it in a form action; failures stay in the `Result`). `src` is a value or an atom: a pristine Draft re-seeds when it changes, an edited one keeps its edits. No source: `useDraft(Spec, undefined)`. Same slot rule as `useLocal`; outside a component it returns a Draft without a slot. |

`useDraft` is a slot hook built on the `@sleekstack/ui/internal` extension point. `effect`, `@sleekstack/core` and `@sleekstack/ui` are peer dependencies.
