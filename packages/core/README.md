# @sleekstack/core

The Effect-native engine: Service Definitions (`service()`), Modules (`module()`), lifetimes, shadowing, enforced module privacy and the scope runtime (`makeAppScope`). The whole graph is validated at build time by `sleekstack check`.

Guides and the generated API reference live in the docs site ([`apps/docs`](../../apps/docs/README.md)): run `pnpm --filter docs dev` and open http://localhost:3000/docs.
