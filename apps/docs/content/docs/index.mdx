SleekStack gives you dependency injection, a service layer and module management for full-stack TypeScript apps. It is built on [Effect](https://effect.website): Tags, Layers and Effects directly, with typed errors. Components are Effects too, through `@sleekstack/ui`, and `@sleekstack/start` adds a server entry on top of it.

## Packages

| Package                | What it does                                                                                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@sleekstack/core`     | Declared Layers, modules and scopes                                                                                                                                     |
| `@sleekstack/runtime`  | The framework-agnostic Effect runtime: `configureRuntime`, `runEffect`, a pluggable control-flow classifier                                                             |
| `@sleekstack/devtools` | Dev-only panel: graph, scopes, atoms, errors                                                                                                                            |
| `@sleekstack/ui`       | Components as Effects with typed services and errors, React components as Guests ([guide](/docs/ui))                                                                    |
| `@sleekstack/router`   | Typed routes, loaders and actions for `@sleekstack/ui` apps                                                                                                             |
| `@sleekstack/query`    | TanStack Query on Effect Layers                                                                                                                                         |
| `@sleekstack/start`    | One server entry: server functions, route handlers and middleware ([ADR 0039](https://github.com/sleekstack/sleekstack/blob/master/docs/adr/0039-start-server-core.md)) |
| `@sleekstack/testing`  | Component tests for `@sleekstack/ui`                                                                                                                                    |
