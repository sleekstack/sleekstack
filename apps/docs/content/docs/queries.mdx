SleekStack's queries are [TanStack Query](https://tanstack.com/query). `@sleekstack/query` is a thin bridge: a `QueryClient` that lives in a Layer's scope, and `effectFn`, which turns an Effect into a `queryFn` / `mutationFn`. Keys, caching, retries, optimistic updates and devtools are TanStack's own. See [Using TanStack Query](/docs/tanstack-query) for what the bridge adds.

## Effect

Provide `QueryClientLive()` in a `LayerProvider` and wrap the tree in `QueryProvider` (from `@sleekstack/react`). The hooks are the official ones from `@tanstack/react-query`.

<include>../../snippets/queries-effect.tsx</include>

- `QueryClientLive(config?)` is a scoped Layer providing `QueryClientTag`. Each `LayerProvider` root that provides it gets its own client; the client is unmounted and cleared when that scope closes.
- `QueryProvider` renders TanStack's `QueryClientProvider` with the nearest scope's client. It suspends while the scope builds.
- `effectFn(effect)` runs the Effect with the services of the layer that built the calling client. It rejects with the original failure or defect, and an aborted `signal` interrupts the fiber. Its `R` is not checked against the layer: a missing Tag rejects at run time.
- Query errors are not typed: TanStack sees a rejected Promise, so `error` is `Error` (or whatever the Effect failed with), not your `E`. This is a deliberate trade for TanStack's ecosystem.

## kit

`cachedQuery` and `mutation` come from `@sleekstack/kit`; `useQuery`, `useMutation`, `useQueryClient` and `QueryProvider` come from `@sleekstack/kit/react`. They lower to TanStack options whose function is an `effectFn`, so `yield*` resolves Tags from the nearest `LayerProvider`. They are named apart from the server-side `query` / `defineQuery` of `@sleekstack/kit/next`, which run once per request and cache nothing.

<include>../../snippets/queries.tsx</include>

- `useQuery` never suspends: check `isPending`. A failure comes back as `error` (a `SleekStackError`), with any earlier `data` kept.
- `staleTime` and `gcTime` are milliseconds; `retry` is a number of retries (default 0).
- `mutate` resolves with the value or rejects with a `SleekStackError`. `useQueryClient()` gives `invalidate`, `refetch`, `setData` and `getData`.
- Keys hash as TanStack's `hashKey` does; a key that cannot be hashed throws `SleekStackError`.
- kit queries have no server prefetch; they fetch on the client.

## `@sleekstack/ui`

`useQuery` and `useMutation` from `@sleekstack/ui/query` read the `QueryClientTag` of the mount layer.

<include>../../snippets/queries-ui.tsx</include>

- `useQuery` shares one `QueryObserver` per key across components (ref-counted) and re-runs the component when its result changes.
- `useMutation` keeps one `MutationObserver` per component instance. `mutate` swallows the rejection (the error is in the result); `mutateAsync` rejects with the original error.
- Under `renderToString` neither hook subscribes or fetches: a prefetched query renders its data, any other renders `pending`, and `useMutation` is idle.

## Build-time checks

`sleekstack check` reads kit `cachedQuery` / `mutation` bodies like action bodies: a Tag that no reaching provider gives is a `MissingDependency` at file:line. A kit key must be a function that returns a tuple literal of literals and its own parameters, like `(id: string) => ['todo', id]`; a parameter typed `any`, `unknown` or a union fails closed as `Computed`. A `@sleekstack/ui` component using the query hooks requires `QueryClientTag` from its mount layer. An `effectFn` body is not checked.

## Devtools

The `@sleekstack/devtools` Queries tab reads the scope client's `QueryCache`. TanStack's own React Query Devtools also work under `QueryProvider`.

## Limits

- Effect-typed query errors are gone: `error` is untyped.
- An optimistic write is only a value in the cache. An item it adds (for example a new task with a temporary id) is not on the server until the refetch replaces it; the showcases do not let users select such an item.
- Server rendering with prefetch is in [Queries on the server](/docs/queries-ssr).
