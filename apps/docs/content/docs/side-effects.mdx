---
title: Side effects
description: Run work when a scope opens and clean it up when it closes, with a scoped Layer.
---

A side effect is a Layer that provides no service. `Layer.scopedDiscard` runs its Effect when the scope opens, and a finalizer added with `Effect.acquireRelease` runs when the scope closes. Wrap it with `declareLayer` and list it in a module's `entries` like any Layer.

<include>../../snippets/effect/side-effects.ts</include>

- An `app` effect runs once per app scope; a `request` effect runs per request scope (one `runEffect` call or one `@sleekstack/start` request); a `component` effect runs per `Provider` subtree.
- If the Effect fails or dies, the scope fails to build with that cause.
- If a finalizer fails, the failure goes to the runtime's `onError` sink as a finalizer failure; it is not thrown.
