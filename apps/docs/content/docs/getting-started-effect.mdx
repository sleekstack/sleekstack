Install core and Effect, plus the adapters you need.

- `pnpm add effect @sleekstack/core`
- `pnpm add @sleekstack/next` and/or `@sleekstack/react`

## Define services

Tags are Effect `Context.Tag` classes. `declareLayer(layer, { lifetime })` wraps a plain Effect Layer with its lifetime. The provided and required Tags come from the Layer's type, which `sleekstack check` reads to validate the modules at build time. `makeAppScope` has no graph: it builds entries in position order, so list a Layer after the Layers it needs.

<include>../../snippets/effect/getting-started.ts</include>

At run time a missing Tag is a `MissingDependency` Effect tagged error; the other graph errors come from `sleekstack check` (see [Errors](/docs/errors)). A module's `entries` can also hold bare Layers; see the [core reference](/docs/api/core).
