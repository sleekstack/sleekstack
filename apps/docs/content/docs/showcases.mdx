[`apps/showcase`](https://github.com/sleekstack/sleekstack/tree/master/apps/showcase) is a team task board built with `@sleekstack/ui` components on Effect Layers. It is a Vite app: run it with `pnpm --filter showcase dev`.

The page mounts the app twice, as Ada (an editor) and Grace (a viewer). Each mount has its own atom store, and a `Provider` scopes the Viewer for everything under it. The code has one folder per domain under `src/modules/` (`identity`, `projects`, `tasks`). Tasks are read and written through `@sleekstack/query`, an unknown project renders a `Boundary` fallback, and the tab title follows the open project through an effect. In development the [devtools panel](/docs/ui-devtools) opens below the demo.

Its tests cover server rendering, streaming, hydration and resume, the folder layering, the size budget of ADR 0022, and one fixture per error code of the Analyzer's component pass (`apps/showcase/fixtures/`).
