## Graph errors

Reported at build time by `sleekstack check` (with file:line). The runtime keeps no graph: it builds in position order and only `MissingDependency` (a Tag not built yet or never provided) is thrown at run time. Privacy, ambiguity, cycles and captive dependencies are build-time only.

| Code                | Triggered when                                                                                                                                              |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MissingDependency` | A service requires a Tag that no entry provides.                                                                                                            |
| `DependencyCycle`   | Services require each other in a cycle (`path` lists it).                                                                                                   |
| `AmbiguousProvider` | Two providers of one Tag sit at the same locality, so Shadowing cannot pick one.                                                                            |
| `ModuleCycle`       | Modules import each other in a cycle (`path` lists it).                                                                                                     |
| `DuplicateModule`   | Two distinct modules share one name.                                                                                                                        |
| `InvalidModule`     | A module config is malformed: an empty name, a `provide`/`entries` item that is not a Layer, or malformed `imports`/`exports`. Thrown by `module()` itself. |
| `CaptiveDependency` | A service depends on one whose lifetime it may not capture, for example `app` on `request`.                                                                 |
| `PrivateDependency` | Something outside a module requires a Tag the module does not export. Build-time only: the runtime does not enforce it.                                     |

## Analyzer read errors

Reported by `sleekstack check` (with file:line) when it cannot read a declaration statically. The analyzer fails closed: an unreadable declaration is an error, never a skip.

| Code                | Triggered when                                                                                                                                                                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Unresolvable`      | A provider, module or Layer cannot be read statically (a computed or dynamically picked value), or a `*.controller.ts` file's path is not a route (outside `server/routes`, a segment of no route form, an optional or splat segment that is not last). |
| `Computed`          | A provide list, import list or name is computed in a way the analyzer cannot evaluate (use literals, local consts or loops over literal lists).                                                                                                         |
| `NonLiteralOptions` | `runEffect` options are not an object literal the analyzer can read.                                                                                                                                                                                    |
| `UnownedAction`     | Several runtimes exist and the analyzer cannot tell which `configureRuntime` file a root belongs to; pass `--entry` to pick one.                                                                                                                        |
| `EmittedSibling`    | Emitted JavaScript or declaration output (`.js`, `.jsx`, `.d.ts`) sits next to its `.ts` source; delete it.                                                                                                                                             |

## Component errors

Reported by `sleekstack check` (with file:line) for projects whose package.json lists `@sleekstack/ui`, the Effect-native component framework ([guide](/docs/ui)). There is one tree per `mount` call.

| Code                  | Triggered when                                                                                                                                                                                                                                                                                            |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MissingDependency`   | A component needs a Tag that no `Provide` or mount layer supplies.                                                                                                                                                                                                                                        |
| `UnhandledError`      | A tagged error in a component's `E` reaches `mount` without a matching `Catch`, or an event closure (`onXxx`) has any error in `E` (closures must handle their errors, even under a matching `Boundary`).                                                                                                 |
| `EffectInsideReact`   | An Effect component is placed under a `fromReact` guest, in its JSX or through its props.                                                                                                                                                                                                                 |
| `Unresolved`          | The analyzer cannot read a component or Layer (`any`, a dynamically picked component). It fails closed: never a skip.                                                                                                                                                                                     |
| `ConditionalSlot`     | A slot hook call (`useLocal`, `useRef`, `useEffect`, `useDerivedAtom`, `useDeferredAtom`, `useAction`, `useOptimistic`, `useDraft`) is not a top-level statement of the component's generator body (`function*` or `Effect.gen`) before any return (inside a condition, loop, nested or helper function). |
| `MissingKey`          | A `.map` / `.flatMap` / `Array.from` callback in child position returns an element, component or fragment without a `key` prop.                                                                                                                                                                           |
| `NonResumableHandler` | An `on(node, { event: h })` entry or a `resume` handler map is not provably a reference to a top-level `const h = defineHandler('literal-id', ...)` (a non-literal id, an inline function, an unreadable loader or handlers object).                                                                      |

A `<Pending>` is transparent to these checks: its content's `E` and `R` belong to the enclosing tree. At run time a failed Pending content renders the matching `Boundary` fallback (on a re-run too, replacing old content); with no match it goes to `onError` and the old content stays. `useSuspenseQuery` fails with `QueryFailed { cause }`.

A `Boundary` fallback is `(error, reset)`; `reset` (type `Reset`) returns `Effect.void`, so it works as `onClick={reset}` or `yield* reset()`. It re-runs only the boundary's children, counts once per failure, and does nothing after the boundary is removed. A `Pending` inside retries its failed content, so a failed `lazy` import loads again. Because a `Boundary` is an instance, its server markup sits in a `<sleek-reactive style="display: contents">` wrapper ([ADR 0035](https://github.com/sleekstack/sleekstack/blob/master/docs/adr/0035-boundary-instance-reset.md)).

A `<Portal container={el}>` is transparent to the checks too: its children's `E` and `R` belong to the tree where it appears, and they read that position's `Provider` layers and atoms. It renders into a `<sleek-portal style="display: contents">` host appended to `el`, so a remount goes to the end of the container. The server renders nothing for a portal: its content and handlers are client-only, and `hydrateMount` builds it fresh.

### Resumable runtime errors

Raised by `@sleekstack/ui` at render or `resume` time as tagged errors (`Data.TaggedError`), not by `sleekstack check`:

| Code                                                      | Raised when                                                                                                                                                                                                                       |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UnsupportedAtom`                                         | `bind` (or `resume`) receives an atom that is not a serializable value-kind atom: a plain atom or a result-kind atom. Carries the bind `key`. Use `Atom.serializable` with a Schema; the manifest holds each key's encoded value. |
| `ManifestInvalid`                                         | The container has no manifest, more than one, or a malformed one.                                                                                                                                                                 |
| `ManifestDecodeFailed`                                    | A bound atom's value fails to decode. `resume` rejects (a wrong seed would render a wrong page); the error names the atom key.                                                                                                    |
| `DuplicateHandler`, `DuplicateBindKey`                    | Two different handlers share an id, or two different atoms share a bind key, in one render.                                                                                                                                       |
| `DuplicateKey`                                            | Two siblings share one `key` prop. Reported to `onError` once per patch; carries the `key`.                                                                                                                                       |
| `SlotMismatch`                                            | A component re-run called slot hooks (`useLocal`, `useRef`, `useEffect` and the others that take a slot) a different number of times than its first run. Carries the instance id and both counts.                                 |
| `PortalContainerMissing`                                  | A `Portal`'s `container` is missing or not attached to the document. The mount fails with it (a re-run reports it to `onError`).                                                                                                  |
| `UnknownHandler`, `HandlerIdMismatch`, `UnsupportedEvent` | A handler id is missing from the `handlers` map, differs from its chunk's declared id, or names a non-bubbling event.                                                                                                             |

## Server Service errors

Reported by `sleekstack check` and the `sleekstack()` Vite plugin (with file:line) for a `ServerService` contract ([ADR 0051](https://github.com/sleekstack/sleekstack/blob/master/docs/adr/0051-server-services.md)).

| Code                               | Triggered when                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ServerServiceFileShape`           | A file declaring a `ServerService` holds a value other than `Data.TaggedError`, `Schema.TaggedError` and `ServerService` classes, is a `*.server.ts` file, or imports one; or two `ServerService` classes share one Tag id.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `ServerServiceMethodShape`         | A contract method takes more than one parameter, is not written out as a function type, does not return an `Effect.Effect<A, E>`, requires services (`R` is not `never`; an implementation built with `implement` may use the request services), or is typed with `any`; or a `Schema.Schema.Type<typeof X>` in it cannot be used: `X` is not an exported Schema value of a module that is not server-only, or the reference is written where the reader cannot follow it (only inline or through a type alias of the same file, as a property, an array element or a union member).                                                                 |
| `ServerServiceTypeNotSerializable` | A Server Service or Controller method's input, success or error type is outside the supported subset (`string`, `number`, `boolean`, `null`, `undefined`, `void`, literals, unions, arrays, plain object types, string-keyed records; `Data.TaggedError` and `Schema.TaggedError` classes, `Redirect` and `NotFound` for Server Service errors): a `Date`, `Map`, `Set`, class instance, function, `bigint`, `symbol`, `unknown`, `any`, tuple, an index signature whose key is not `string`, intersection with a non-object, or recursive type. The message names the member path, such as `input.tags[]`. A Controller's errors are not read.      |
| `ServerFileInClientGraph`          | A server-only file (`*.server.ts`, `*.controller.ts`, `*.rpc.ts`, `*.layer.ts`, or a `_defaults.ts`, `rpc.ts` or `_app.ts` under the server directory) is value-imported, directly or through other modules, by a module that imports `virtual:sleek/server` or `virtual:sleek/rpc` (a browser entry). The message lists the import chain. `import type` and imports from tests or other server code are not reported. The client build fails the same way. An RPC method whose Schema reference or error class lives in a server-only module, the RPC File or Controller itself included, is reported too, because its generated client imports it. |

## Controller errors

Reported by `sleekstack check` (with file:line) for each `*.controller.ts` file under `server/routes` ([ADR 0053](https://github.com/sleekstack/sleekstack/blob/master/docs/adr/0053-file-routed-controllers.md)). Controllers are roots of the check, so an app with only Controllers is checked too: a service a method requires that no `wrap` above it (its `next` requirements minus its result's), no `start({ layer })`, no Layer File and no request service provides is a `MissingDependency`. A class Controller's declared Tags count as requirements by the same rule, and one nobody provides is a `MissingDependency` at the declaration, naming the class. A Controller whose default export is `records(Record)` ([ADR 0057](https://github.com/sleekstack/sleekstack/blob/master/docs/adr/0057-served-records.md)) serves `GET` and `PATCH`, and the record's adapter Tag is its requirement by the same rule: one no Layer File provides is a `MissingDependency` at the default export.

| Code                       | Triggered when                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ControllerMethodShape`    | A default export that is not a class Controller, or an export that differs from a method name only in case (`get`, `Post`); a method is not written as a function, takes more than one parameter, an input that is not one object, an input key other than `params`, `query` and `body`, or a `body` on `GET`, `HEAD` or `OPTIONS`; it is typed with `any` or does not return an Effect; its whole input is one Schema reference; or a `params` or `query` value cannot decode from a string (a referenced Schema that does not encode to strings, an object, `null`, a number or boolean literal).. A class Controller ([ADR 0056](https://github.com/sleekstack/sleekstack/blob/master/docs/adr/0056-class-controllers-and-service-classes.md)) does not extend `Controller(...)` directly, has no HTTP-named generator method, has an HTTP-named member that is not a generator method or a method without a written `Gen` (a local alias of the whole `Gen` included), or sits beside a named Controller Method export |
| `ControllerParamsMismatch` | The keys of a method's `params` differ from its path's params, including a method with no `params` on a path that has them. The message lists both.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `RecordsRouteShape`        | A default export `records(...)` sits at a path that does not end in exactly `[id]`, calls a `records` that is not the one of `@sleekstack/start`, or passes an argument that does not resolve to a `const` holding a `defineRecord(...)` call, a record without an `adapter`, or one whose fields' Schemas need a Service. A default export that is not a call of `records` is a `ControllerMethodShape`, as before.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `RecordsMethodCollision`   | A Controller default-exporting `records(...)` also exports a named `GET` or `PATCH`, which it serves. Other named methods (`DELETE`) are ordinary Controller Methods.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## Server file errors

Reported by `sleekstack check` (with file:line) for the server files found by name ([ADR 0054](https://github.com/sleekstack/sleekstack/blob/master/docs/adr/0054-server-auto-wiring.md)): each `*.layer.ts` file anywhere in the TypeScript program except tests (`__tests__/`, `test/` and `tests/` directories, `*.test.*` and `*.spec.*` files), and the Server Root, the server directory's `_app.ts`. Layer Files are roots of the check. Each one's default export is a Layer, read from its type: its `ROut` is what it provides and its `RIn` what it requires. They are composed by requirement, files that do not depend on each other in path order, and a requirement no Layer File provides is a `MissingDependency`. A Tag `start({ layer })` provides as well is shadowed by it, not a conflict.

| Code                | Triggered when                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LayerFileCycle`    | Layer Files require each other in a cycle. The message lists it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `LayerFileConflict` | Two Layer Files provide the same Tag. The message names both.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `ServerFileShape`   | A `*.layer.ts` file has no default export (a type-only one is erased), or one that is not a Layer or is typed `any`, in its `ROut` or `RIn` too; or the Server Root exports anything but `onError`; or an RPC File's service name (its basename in PascalCase, or its `service` export) is not of the form `[A-Za-z][A-Za-z0-9]*`, or its `service` export is not a string literal; or the RPC Manifest's default export is not an object literal (or `rpc(...)` of one) whose entries are `Service: { method: 'VERB route' }` string literals. |

## RPC errors

Reported for each RPC File (`*.rpc.ts` under the server directory) and the RPC Manifest (the server directory's `rpc.ts`) ([ADR 0054](https://github.com/sleekstack/sleekstack/blob/master/docs/adr/0054-server-auto-wiring.md)). An RPC File's exported functions are the methods of one Server Service named after the file; `wrap`, `bodyLimit`, `origins` and `service` are options and other values are not methods. A Manifest entry `method: 'VERB route'` wraps the Controller Method `VERB` of the route, its path under the routes directory without `.controller.ts`. Methods are read like Server Service methods, so a type outside the subset is `ServerServiceTypeNotSerializable`.

| Code               | Triggered when                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RpcMethodShape`   | An RPC File method is not a function declaration or an arrow or function expression assigned to an exported `const` (an `Effect.fn` value, for one), is generic or `async`, takes more than one parameter or one without a written type, has no written `Effect.Effect<A, E, R>` return type, is typed with `any`, or requires a generated Tag; or a Manifest entry wraps a Controller Method that is not written out the same way or returns a `Response`. A wrapped method is reported once, at the Manifest entry. |
| `RpcRouteUnknown`  | A Manifest entry names a route no Controller serves, or a method its Controller does not export (a removed one included).                                                                                                                                                                                                                                                                                                                                                                                             |
| `RpcNameCollision` | An RPC File's Tag name or a Manifest key equals another one, a `ServerService` id, a Layer File output Tag key or a `serverFn` id: Context keys are global strings. The message names both.                                                                                                                                                                                                                                                                                                                           |

## Runtime

- `@sleekstack/runtime`: `runEffect` called before `configureRuntime` rejects with `RuntimeNotConfigured`. A failure or defect rejects as `Effect.runPromise` does; defects, finalizer failures and failed layer builds reach `onError(cause, { phase })`. Values your `isControlFlow` classifies are rethrown untouched and never reported, including when thrown while the app Layer builds.
- `@sleekstack/start`: `DuplicateServerFn` and `InvalidServerFnId` fail the `start` call, and so does `InvalidOrigin` for a `start({ origins })` entry that is not a bare origin. A Controller or `_defaults.ts` file is read on the first request, so an `origins` export with such an entry (`InvalidOrigin`) or a `bodyLimit` export that is not a positive integer fails that request's app load instead, naming the file. A Controller's routing and decode failures reach its `wrap` ([Controllers](/docs/controllers#failures-and-wrap)). A server function call that cannot decode its input answers 400 with a `DecodeError`; an undeclared failure or a defect reaches the error sink and answers an empty 500 ([ADR 0039](https://github.com/sleekstack/sleekstack/blob/master/docs/adr/0039-start-server-core.md)).
