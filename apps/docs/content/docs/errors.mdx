## Graph errors

Reported at build time by `sleekstack check` (with file:line). The runtime keeps no graph: it builds in position order and only `DuplicateTag` (a kit check) and `MissingDependency` (a Tag not built yet or never provided) are thrown at run time. Privacy, ambiguity, cycles and captive dependencies are build-time only.

| Code | Triggered when |
| --- | --- |
| `MissingDependency` | A service requires a Tag that no entry provides. A kit action whose dep is not provided rejects with it too. |
| `DependencyCycle` | Services require each other in a cycle (`path` lists it). |
| `AmbiguousProvider` | Two providers of one Tag sit at the same locality, so Shadowing cannot pick one. |
| `ModuleCycle` | Modules import each other in a cycle (`path` lists it). |
| `DuplicateModule` | Two distinct modules share one name. |
| `InvalidModule` | A module config is malformed: an empty name, a `provide`/`entries` item that is not a Layer, or malformed `imports`/`exports`. Thrown by `module()` itself. |
| `CaptiveDependency` | A service depends on one whose lifetime it may not capture, for example `app` on `request`. |
| `PrivateDependency` | Something outside a module requires a Tag the module does not export. Build-time only: the runtime does not enforce it. |

## Analyzer read errors

Reported by `sleekstack check` (with file:line) when it cannot read a declaration statically. The analyzer fails closed: an unreadable declaration is an error, never a skip.

| Code | Triggered when |
| --- | --- |
| `Unresolvable` | A provider, module or Layer cannot be read statically (a computed or dynamically picked value). |
| `Computed` | A provide list, import list or name is computed in a way the analyzer cannot evaluate (use literals, local consts or loops over literal lists). |
| `UnnamedEffect` | An `effect()` inside a module has no literal `name`. |
| `NonLiteralOptions` | `runEffect` options are not an object literal the analyzer can read. |
| `UnownedAction` | Several runtimes exist and no `configureRuntime` file imports the action; pass `--entry` to pick one. |
| `EmittedSibling` | Emitted JavaScript or declaration output (`.js`, `.jsx`, `.d.ts`) sits next to its `.ts` source; delete it. |

## Component errors

Reported by `sleekstack check` (with file:line) for projects whose package.json lists `@sleekstack/ui`, the Effect-native component framework MVP. There is one tree per `mount` call.

| Code | Triggered when |
| --- | --- |
| `MissingDependency` | A component needs a Tag that no `Provide` or mount layer supplies. |
| `UnhandledError` | A tagged error in a component's `E` reaches `mount` without a matching `Catch`. |
| `EffectInsideReact` | An Effect component is placed under a `fromReact` guest, in its JSX or through its props. |
| `Unresolved` | The analyzer cannot read a component or Layer (`any`, a dynamically picked component). It fails closed: never a skip. |

## Kit checks

| Code | Triggered when |
| --- | --- |
| `DuplicateTag` | One provide set holds two distinct Tag objects with the same key. |
| `InvalidTag` | `tag()` gets an empty or non-string name, or a dep is neither a `tag()` nor a named class. |
| `InvalidQueryKey` | A `cachedQuery` key holds a value with no stable JSON form (a function, `BigInt`, symbol or cycle). `details.key` holds it. |

## Query SSR errors (kit)

| Code | Triggered when |
| --- | --- |
| `QueryDecodeFailed` | A `serializable` query's `decode` throws on server-prefetched data. `details.key` names the query. |
| `NoServerRunner` | A server render reads an un-prefetched query and no server runner is registered: import `@sleekstack/kit/next` on the server, or prefetch the query. |

See [Queries on the server](/docs/queries-ssr#kit).

## Runtime errors

| Code | Triggered when |
| --- | --- |
| `LayerFailed` | A Layer factory or constructor (or an `effect()` function) throws or rejects while its scope builds. `details.cause` holds the message. |
| `HandlerFailed` | A kit action/query handler throws something other than `fail()`. |
| `CleanupFailed` | A `withCleanup` cleanup or an `effect()` teardown throws. It is not thrown to you: `onFinalizerError` receives a plain `FinalizerError` (`{ message, tag }`) instead. |
| `Unknown` | Anything else. In kit this includes `useService` with no `LayerProvider` above or a Tag the provider does not provide, an action/query called before `configureRuntime`, `prefetch` of a query without `serializable`, and `mutate` called during a server render (its `cause` is an `Error` named `MutateDuringRender`). |

`fail(message)` is not an error code: an action resolves `{ ok: false, error }` and a query rejects with a plain `Error` carrying the message.

## Effect-native adapters

- `@sleekstack/runtime` (and `@sleekstack/next`): `runEffect` called before `configureRuntime` rejects with `RuntimeNotConfigured`. A failure or defect rejects as `Effect.runPromise` does; defects, finalizer failures and failed layer builds reach `onError(cause, { phase })`. Values your `isControlFlow` classifies (in `@sleekstack/next`, Next's `redirect()`/`notFound()`) are rethrown untouched and never reported, including when thrown while the app Layer builds.
- `@sleekstack/react`: `useService` with no provider, or an unprovided Tag, throws a plain `Error`; a failed scope build is rethrown from `useService` to the nearest error boundary.
