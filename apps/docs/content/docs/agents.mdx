`sleekstack check` and `sleekstack explain` give an agent the same feedback they give you, so it can fix a graph or component error without guessing.

## Check and explain

`npx sleekstack check` exits 0 when clean, 1 on violations and 2 on a usage error. Each error prints `file:line CODE: message`, then indented `fix:` lines (most likely first) and a `docs:` line. `--json` carries the same `fix` and `docs` fields. `sleekstack explain <CODE>` prints a code's rule, fixes and docs path, and exits 2 for an unknown code. See [Errors](/docs/errors) for the full list.

Add `npx sleekstack check` to your `AGENTS.md` as the command to run after changing SleekStack code, and to CI before the tests.
