`@sleekstack/router` is a separate package for apps on the `@sleekstack/ui` host (ADR 0036). A route table is a `const` object of path strings, and params are typed from those strings with no code generation.

<include>../../snippets/routing/app.tsx</include>

- `loader(key, schema, effect)` declares a loader. A page reads it with `useLoader` under `Pending`; a typed error reaches the nearest `Boundary`.
- `redirect(to)` and `notFound()` in a loader or action are control flow. `handle` answers 302 or 404; in the browser the router navigates or shows the not-found page. More than 10 redirects in a row fail with `RedirectLoop`.
- `handle` runs a page's loaders before rendering, so the response has the right status. A loader error with a numeric `status` sets it; any other is a 500. The results reach the client through `Transfer`, so it does not load them again.
- `startRouter` handles same-origin link clicks, back and forward, and scroll restoration. A newer navigation interrupts the pending one and stops its loads.
- `Link` prefetches a route's code and loaders on hover or focus; `prefetch={false}` opts out. `action(run)` takes any form a form `action` takes.
