# docs

The SleekStack documentation site: a static site built with `@sleekstack/ui` and `@sleekstack/ui-vite` (MDX pages, build-time search index and Open Graph images), with an API reference generated from TSDoc.

```bash
pnpm --filter docs dev     # Vite dev server, pages served through @sleekstack/start (generates the API reference first)
pnpm --filter docs build   # generate:api, vite build (one index.html per page, search-index.json, og/*.png), then the link check
pnpm --filter docs test    # link check, API coverage, guides, layout and search, stale-phrase check
```

- Guides live in `content/docs/*.mdx`; `content/docs/meta.json` is the order file.
- `content/docs/api/` is generated by `scripts/generate-api.mjs` (TypeDoc + typedoc-plugin-markdown) and gitignored. Entry points come from each package's `exports` map, else its `types` field (`scripts/entry-points.mjs`, shared with the coverage test).
- `VITE_DOCS_BASE` (default `/docs`) is the route prefix and `VITE_DOCS_SITE` (default `https://sleekstack.dev`) the origin used for absolute `og:` URLs. Internal links in the content are written with the prefix, so they must match `VITE_DOCS_BASE`.
- `src/site.tsx` builds a page for both the server entry (`src/server.tsx`, prerender) and the browser entry (`src/main.tsx`, hydration). `src/app.tsx` is the dev server's `start` entry.
- The Open Graph font is `fonts/inter-700.woff` (Inter, SIL OFL).
