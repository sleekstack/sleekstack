# 0056. Class Controllers and Service Classes: generator methods, dependencies declared once

## Status

Accepted. Reverses the "Decorators and class controllers" rejection of ADR 0053 and extends ADR 0054's wiring. The named-export Controller of ADR 0053 stays valid. Built in spec fn-71.

## Context

ADR 0053 rejected class controllers because "a class adds a second way to provide services". That held while a class meant either decorators or a hand-built `Layer` per class. Realworld's `Articles` (branch `realworld-articles-service`) shows a smaller form: a base class whose subclass is plain generator methods (`*get(slug) { ... yield* ... }`). The base class makes each method an Effect (`Effect.fn`, spanned), is itself the Tag, takes its dependencies as a record of Tags (`{ db: Db }` on `this`) and builds `Default` from them. A service written this way has no `Effect.Service` options object, no per-method wrapper and no hand-written Layer. A Layer File default-exports `Articles.Default`, so ADR 0054 already finds and composes it.

A Controller written as a function still repeats the same preamble in every method (`const articles = yield* Articles`) and restates `Db | Articles | Viewer` in each signature.

## Decision

- **`Service`, `Controller`, `Gen` and `accessors` are public exports of `@sleekstack/start`, with the type `ControllerMethodsOf`; `Service` is the base class of a service.** `class Articles extends Service<Articles>()(key, { db: Db }) { *get(...) {} }`. The record names the Tags the service needs; each is on `this` under its name. `Articles.Default` is the Layer, built once with the app's Layer. Each generator method, inherited ones included, is wrapped in `Effect.fn` (spanned `<key>.<method>`) when the instance is built, so it runs as an Effect also when another method calls it with `yield* this.get(...)`; a non-generator method is left alone. The class is its Tag. TypeScript types the method as a `Generator`, so a caller that is not itself a generator uses `accessors(Articles)`. A Service may declare another Service; the Layers compose by requirement.
- **A Controller may be a class.** A `*.controller.ts` file may `export default class extends Controller({ articles: Articles }) { *GET(input) {} }` instead of named exports. The path sets the URL and the method names are the HTTP methods, as in ADR 0053. A file is one form or the other: a default class together with a named Controller Method export is `ControllerMethodShape`.
- **Dependencies are declared, not yielded, and a Controller instance is built per request.** The record names the Tags; before the method runs, the request's Effect resolves each from its context and builds the instance, so each is on `this` as the service value. A declared Tag may therefore be a per-request service (`Viewer` provided by a `wrap`, `Request`, `Cookies`) as well as one a Layer File provides. The class's requirements are its declared Tags together with the `R` of its methods' written `Gen`. `sleekstack check` reports one that no `wrap`, Layer File, `start({ layer })` or request service provides as `MissingDependency` naming the class, as it does for a function Controller. A `Service` is built once with the app's Layer; a Controller is built per request, so a Controller instance may hold request data in its fields and nothing it holds outlives the request. The base class wraps each generator method once per class, not once per instance (spanned `<ClassName>.<method>`, or `Controller.<method>` for the unnamed `export default class`), and calls the wrapped method with the instance as `this`. The class's static `run(method)` is the generated entry's `run`: per request it resolves the declared Tags, builds the instance and calls the method. A missing declared Tag at run time is an ordinary missing-service defect (500, reaching `onError`). `Controller()` and `Controller({})` declare nothing.
- **The method signature is written out, as in ADR 0053.** A generator method cannot return `Effect`, so `@sleekstack/start` exports `Gen<A, E = never, R = never>`, a `Generator` of yielded Effects ending in `A`. `*GET(input: { params: ... }): Gen<Schema.Schema.Type<typeof Article>, NotFound, Viewer>`. The analyzer reads `input` and the first `Gen` argument exactly as it reads the input and the `A` of an `Effect` today, and `E` and `R` as it reads them (a missing one is `never`). It finds `Gen` in the written return type node by the imported symbol, so an aliased import works and a local alias of the whole `Gen` is refused as a missing written `Gen`: `Gen` is an alias of `Generator`, and the resolved type keeps no alias to read. TypeScript checks the body against the written `Gen`.
- **`_defaults.ts` is unchanged, and a class Controller's own options are named exports beside the class.** `export const wrap`, `bodyLimit` and `origins` next to `export default class`, read by the option reader that function Controllers use. They are not static members and not instance methods, so a `wrap` cannot read the declared dependencies; it provides services to them, because it runs before the instance is built.
- **A Controller class is not an RPC source, but its methods are Controller Methods.** An RPC Manifest (ADR 0054) entry may name a method of a class Controller; the generated entry, and the Manifest's wrapper, call it through the class's `run`. The generated declaration types a class file's `ControllerModules` entry as `ControllerMethodsOf<typeof default>`: the HTTP-named methods as functions returning the Effect of their written `Gen`.
- **Defects at class definition.** A declared name that is `constructor`, a method of the class or (on a Controller) an HTTP method name, and a Service key another file already used, throw when the class is defined or first built. A file that runs again (a dev reload) may define its keys again; two Services with one key in the same file are not caught.

## Consequences

- A new `AnalyzeCode` is not needed: `ControllerMethodShape` covers a class that does not extend `Controller(...)` directly, has no HTTP-named method, has a non-generator member with an HTTP name or a method without a written `Gen`, and mixed forms. `MissingDependency` covers declared dependencies, at the declaration line and naming the class.
- The analyzer reads class members and the `Controller(...)` call's record, which is new reading code beside the function reader. The report's `ControllerDecl` gains `kind` (`'functions' | 'class'`) and `declared`, and an `RpcMethod`'s `controller` gains `kind`, which the Vite plugin uses to generate a class entry.
- Realworld shows both forms: its article Controllers are class Controllers declaring `Articles` and lose the `Effect.gen` preamble and the `const articles = yield* Articles` line; the user and profile Controllers stay named exports. A declared dependency that no method reads (the comment Controllers reach `Articles` through shared functions) only documents the need.
- `ADR 0053` names no class form; its "Rejected" bullet is superseded by this ADR for the form described here only. Decorators stay rejected.
- `accessors` exists only because a class cannot type its own statics from its own body (a base class whose static side maps over `Self` fails with "recursively references itself as a base type"). One line per service in a test or a non-generator caller.

## Rejected

- **Decorators.** Still rejected (ADR 0053).
- **Yielding the service in each method.** It keeps the analyzer simple but repeats the preamble and hides what a Controller needs from `check` until it reads the method bodies.
- **A directory `_defaults.ts` as a base class.** It would replace the inheritance of options by directory with class inheritance and needs its own decision.
- **`Effect.Service` with `accessors: true`.** Its accessors are typed from the constructor's return value, so methods written in the class body get none.
- **A once-built Controller.** It was the recommendation, because a field would then be shared by every request. It was declined: per-request construction lets a declared dependency be the viewer.
- **Making each method a class property wrapped in `Effect.fn`.** It works (`get = Effect.fn('...')(function* (this: Articles) {})`) but needs the wrapper and a `this` annotation on every method.
