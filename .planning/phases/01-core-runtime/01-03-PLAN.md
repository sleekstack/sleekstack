<objective>
Implement `@sleekstack/react`'s single-provider runtime: the `ProviderContext`, the `LayerProvider` component that owns a hidden `ManagedRuntime` lifecycle, and the `useService` Suspense hook with the three-state cache. Rewrite the React public type surface and barrel to the target API.

This delivers SleekStack's ONE thing that must work (per CLAUDE.md): `useService(Tag)` resolves from the nearest `LayerProvider`, suspends on first acquisition, returns synchronously from cache thereafter, with deterministic cleanup on unmount. Nested-provider inheritance and shadowing are deliberately deferred to Plan 01-04 (this plan handles a single provider scope).

Purpose: Bridge Effect 3.x's `ManagedRuntime` to React's mount/unmount + Suspense model while keeping Runtime/Scope/Fiber fully hidden (ADR 0001 / REACT-07).
Output: `context.ts`, `LayerProvider.tsx`, `useService.ts`, rewritten `types.d.ts`, rewritten `index.tsx` barrel — turning the REACT-01, REACT-03, REACT-04, REACT-06, REACT-07, REACT-08 tests green.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| component → useService | The Tag argument and the surrounding render context are developer input crossing into the hook |
| LayerProvider lifecycle → Effect runtime | React mount/unmount drives ManagedRuntime creation/disposal |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | useService missing-provider + acquisition error messages | mitigate | Error messages name the service/Tag by identifier and the remediation step only; they do not embed internal Effect call stacks or runtime internals (01-RESEARCH.md Security Domain, Stack trace leakage). |
| T-03-02 | Denial of Service / Reliability | ManagedRuntime disposal after unmount | mitigate | `dispose()` is idempotent and the ref is reset to null in cleanup; calling after unmount (Strict Mode double-invoke) is safe and does not leak runtimes (01-RESEARCH.md Pitfall 1, verified). |
| T-03-03 | Tampering | Runtime/Scope/Fiber exposure | mitigate | The barrel exports only LayerProvider + useService; Runtime/Scope/Fiber are never exported or passed via props (ADR 0001 / REACT-07) — verified by negative grep on index.tsx. |
| T-03-04 | Elevation of Privilege | module export isolation | accept | Per ADR 0002, isolation is type-level only; useService does not runtime-enforce that a requested Tag was exported. Accepted edge case (dynamic tag-as-value usage escapes enforcement). |
</threat_model>
