# fn-71-class-controllers-and-service-classes.5 realworld: article Controllers become classes

Touches: [apps/realworld/server/routes/api/**, apps/realworld/server/articles.ts, apps/realworld/server/comments.ts, apps/realworld/server/articles-api.rpc.ts, apps/realworld/server/comments-api.rpc.ts, apps/realworld/test/**, apps/realworld/src/server.gen.d.ts, apps/realworld/README.md]

## Description
Move the article Controllers of realworld onto the class form, declaring `Articles`, with behavior, routes and statuses unchanged.

**Size:** M
**Files:** `apps/realworld/server/routes/api/**` (articles, feed, `[slug]`, favorite, comments, comments `[id]`, tags), `apps/realworld/server/comments.ts`, the two RPC files if they gain from `accessors`, `apps/realworld/test/**`, `apps/realworld/src/server.gen.d.ts` (regenerated, never hand-edited), `apps/realworld/README.md`
**Touches:** [apps/realworld/server/routes/api/**, apps/realworld/server/articles.ts, apps/realworld/server/comments.ts, apps/realworld/server/articles-api.rpc.ts, apps/realworld/server/comments-api.rpc.ts, apps/realworld/test/**, apps/realworld/src/server.gen.d.ts, apps/realworld/README.md]

### Approach
- Each article Controller file becomes `export default class extends Controller({ articles: Articles })` with HTTP-named generator methods and a written `Gen<...>` return. The directory `_defaults.ts` `wrap` and the named option exports stay as they are. The answer envelope, statuses (201 through `ResponseStatus`, 204 for `void`) and the `articles/feed` versus `articles/[slug]` order are unchanged.
- `comments.ts` and the comments Controllers depend on `Articles` through `articles.at`; move them only where the class form reads better and keep their tests intact.
- The RPC file `articles-api.rpc.ts` keeps its written signatures; it may call `Articles` through `accessors` or `yield*`.
- Behavior pin: the 161 realworld tests, including every case of `rest.test.ts` (unknown route, 405, malformed escape, 413 three ways, malformed JSON, bad token, non-numeric comment id). No test is edited except for imports.
- `server.gen.d.ts` is regenerated by the plugin: commit it as written.

### Investigation targets
**Required**:
- `apps/realworld/server/routes/api/articles/[slug].controller.ts`, `articles.controller.ts`, `articles/feed.controller.ts`, `articles/[slug]/favorite.controller.ts`, `tags.controller.ts`
- `apps/realworld/server/routes/api/_defaults.ts` - the `wrap` the classes inherit
- `apps/realworld/test/rest.test.ts`

### Acceptance
- [ ] every article Controller is a class declaring `Articles` and `pnpm --filter realworld check` exits 0 with no `ControllerMethodShape` or `MissingDependency`
- [ ] `pnpm turbo run test typecheck --filter=realworld` passes with the same 161 tests and no test body edited
- [ ] `pnpm --filter realworld build` exits 0 and the client build excludes the Controllers
