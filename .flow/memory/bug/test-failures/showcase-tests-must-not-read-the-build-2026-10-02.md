## Problem
A showcase test rendered /graph from the real .sleekstack/report.json, which is gitignored and only generated by prebuild/predev, so a clean `pnpm test` fails with ENOENT.

## Solution
Spy on readReport with a fixture (apps/showcase/src/__tests__/graph.test.ts); the analyzer side stays pinned by packages/cli check.test.ts.

## Prevention
Run showcase tests with .sleekstack/ moved aside before committing a test that reads build output.
